## 各ラウンドでやったこと

**1回目：文言**
- 「今日は、…今日のうちに」のような「今日」の二重表現を10件解消しました。
- 夜は行動を「眠る前のひとときか明日の朝に」と言い換えるようにしました。
- 復縁・婚活で、共感文と前置きが同じ言い回しになる箇所を修正しました。
- 「十分だけ」を「10分だけ」にし、じゅうぶんと読まれる恐れをなくしました。
- 読み上げの一文が80字を超えないよう分割しました。
- 4,620通りを機械で検査し、問題0件になるまで直しました。

**2回目：アクセシビリティ**
- 薄い文字色（2.8:1）、金色の文字（2.6:1）、主ボタン（3.1:1）を4.5:1以上に直しました。
- 価格タグ、朝夜切り替え、「聴きました」チップの色も修正しました。
- フォーカス表示、矢印キー操作、progressbar、状態の読み上げを追加しました。
- axe で違反0件を確認しました。

**3回目：専用感と打ち合わせ**
- 「朱里からのひと言」枠を追加しました。
- 監修メモに朱里様の読み方と一言を記録できるようにし、結果・音声へすぐ反映させ、Markdown で書き出せるようにしました。
- 打ち合わせ用のQRコードを表示できるようにしました。

**4回目：アプリらしさと音声**
- manifest、PNGアイコン、Service Worker を追加しました。
- 始まりと終わりに鈴の音を鳴らすようにしました。
- Safari 向けに、話している時だけ止める方式にしました。
- 端末の声を選べる設定を追加しました。

**5回目：細部**
- 22枚のカード面を一覧で点検し、3点を修正しました。
- 320px幅で起きた横はみ出し、見出しの1文字だけの折り返し、ボタン文言の折り返しを直しました。
- `text-wrap` による折り返しの改善（対応ブラウザのみ）、`<noscript>` を追加しました。

## 検証方法（再現できます）
- `node tests/content-check.js`：文言を4,620通り検査します（依存なし）。
- `node tests/e2e.js`：iPhone 13 と Pixel 7 のエミュレーションで、回答 → カード → 音声完了 → ペイウォール → 同日の再訪 → 翌日 → 途中離脱ユーザーを通します（Playwright が必要）。
- そのほか作業中に、TTS失敗からの復帰、朱里様の言葉の反映、QRコード、Service Worker、axe 全10画面、320px幅、声の選択を確認しました。

## 残っているリスク（点数には含めていません）
1. **実機の音声**：iPhone Safari と Android Chrome の実際の声、話す速さ、マナーモード時の挙動は未確認です（テストは日本語音声のスタブ）。話す速さの違いは再生中の補正で吸収する設計ですが、公開前に必ず実機で聴いてください。
2. **朱里様の確認事項**：名前の読み（あかり／しゅり）と、毎朝届ける言葉の温度感（鑑定サイトの強い言葉か、穏やかな言葉か）。
3. **Instagram の色味**：アクセス制限で投稿を見られなかったため、配色は仕様案（藤色×生成り）に合わせています。
4. **SPEC.md**：イベントの属性名、データの形、認証は仮のままです。
